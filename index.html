Standar Mutu ISO & Rekayasa Tabel Word XML

Solusi mutakhir mengatasi kelemahan AI konvensional yang kerap menghasilkan tabel rusak, teks terpotong, atau sel terbelah saat berganti halaman.

📐

Locked Column Widths (dxa)

Menyuntikkan w:tblGrid dan w:tcW w:type="dxa" di setiap sel dengan batas printable width A4 tepat 6.10 inci (8.784 dxa). Tabel tidak akan menyusut atau melar tak beraturan di berbagai versi Word.

🛡️

Anti-Row-Split (cantSplit)

Menerapkan <w:cantSplit/> pada setiap baris tabel. Menjamin tidak ada baris deskripsi Sub-CPMK atau materi kuliah yang terbelah separuh di bawah halaman dan separuh di halaman berikutnya.

🔁

Repeating Header (tblHeader)

Menerapkan elemen <w:tblHeader/> pada baris judul tabel Silabus 16 Minggu. Kepala tabel otomatis berulang di halaman baru sehingga dokumen tetap terbaca profesional dan rapi.

⚖️

Presisi Bobot Evaluasi 100%

Memastikan komponen penilaian Presensi (10%), Tugas (20%), Kuis (10%), UTS (30%), dan UAS (30%) selalu berjumlah tepat 100%, sinkron dengan seluruh instrumen RPS terkait.

📊

Skala 7 Konversi Nilai Resmi

Mengintegrasikan tabel rentang nilai huruf A (80–100), B+ (75–79), B (70–74), C+ (65–69), C (56–64), D (45–55), hingga E (0–44) sesuai pedoman akademik resmi UNIROW.

🎓

KOP & Lembar Pengesahan Resmi

Dilengkapi KOP resmi dua garis ganda, logo universitas beresolusi tinggi, serta kolom tanda tangan dosen pengampu dan perwakilan mahasiswa sebagai kesepakatan belajar yang sah.

Panduan Instalasi & Penggunaan

Gunakan skill ini pada ekosistem AI favorit Anda: Google Antigravity, Claude Code, Cursor IDE, atau CLI mandiri.

# 1. Kloning repository ke folder skills workspace Antigravity Anda:

git clone https://github.com/mariofahmi/skillISO.git .agents/skills/kontrak-kuliah-rps

# 2. Panggil skill di jendela chat Antigravity:

/kontrak-kuliah-rps buatkan kontrak kuliah dari file RPS_Pancasila.docx

# Pasang di Cursor IDE (.cursorrules atau workspace rules):

git clone https://github.com/mariofahmi/skillISO.git .cursor/skills/kontrak-kuliah-rps

# Minta Cursor Composer menyusun dokumen:

Berdasarkan instruksi di SKILL.md, buatkan berkas kontrak kuliah ber-KOP resmi untuk seluruh silabus semester ini.

# Pasang di Claude Code CLI:

git clone https://github.com/mariofahmi/skillISO.git ~/.claude/skills/kontrak-kuliah-rps

# Jalankan engine langsung via terminal Python:

python scripts/build_kontrak.py --rps "path/ke/RPS.docx" --out "output/"

# Atau jalankan batch untuk seluruh RPS sekaligus:

python scripts/batch_generate_all.py
